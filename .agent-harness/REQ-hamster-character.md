## 0. 背景（コードを読んでも分からないこと）

当初の中心仮説「自分の画像1枚を飼う」は本人判断で放棄。理由: 1枚絵は細切りでもポーズ変化に限界がある一方、
自前キャラは**コードで脚まで描ける**ため走りの上限が高い。ハムスター採用の決め手は
①CPU＝回し車のメタファー ②円運動でループの継ぎ目が原理的にゼロ ③将来のWindowsトレイ（正方形）にそのまま収まる。
既存の走る猫（22/24合格）は当初第2キャラとして残したが、**2026-08-29に本人指示で削除**（ハムスター単独・カピバラ用の器のみ維持）。
同日指示で**感度は「敏感」固定・UIごと撤去**（ユーザーがいじれない状態にする）。

## 3. ハムスター＋回し車の描画仕様

**レイアウト（canvas 42x22pt）**: ホイール外径20pt・中心(21, 11.5)。二重の外輪＋横桟5本＋中心軸。
下に小さな台座（支柱＋足）。影は台座下に**固定・脈動なし**の薄い楕円。

**ハムスター**: 右向き・ホイール内の下部。丸い体（金茶＋白い腹）・耳・目・短い尻尾・**4本脚**。
脚は前後ペアで交互に振る（コードで描くので細切りではなく本物のポーズ変化）。体はわずかに上下（±0.5pt）。

**回転**: ホイール角度 = 2π×phase（既存 `PetMotionClock` を流用。周期=`cycleDuration(cpu:)`＝1回転）。
回転向きは**ハムスターの足元でホイール表面が後方（左）へ流れる向き**。脚サイクルはホイール1回転につき2歩期。

**状態表現**:
| 状態 | 表現 |
|---|---|
| resting | **丸まって睡眠**（ホイール停止・脚たたむ・目閉じ・呼吸で体が±0.3ptだけ膨縮）。S7: アイドルは静かに |
| normal / running | 走行。速度はCPU連続連動（既存） |
| sweating | 走行＋汗滴（既存オーバーレイ流用・位置はホイール右上へ調整） |
| onFire | 走行＋炎（ホイール左後方・本体と重ねない）。ホイール回転は上限で頭打ち |

**🔴 エイリアシング防止（要件層・テスト必須）**: 桟5本の回転は速いとストロボ効果で逆回転・明滅に見える。
**どのCPU値・どのfpsでも「1フレームあたりの回転角 < 桟間隔(72°)の50%」**を保証すること。
必要なら回転専用の周期下限（例: 1回転0.9s）を桟側に設け、**脚の回転数だけ**を速度感の担い手にする。

## 4. UX5階層からの追加仕様（3件）

- S9（戦略層）: 速度感の主役は**脚とハムスターの必死さ**。ホイールは回りすぎない（上記の上限）
