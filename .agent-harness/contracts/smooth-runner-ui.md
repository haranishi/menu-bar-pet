# 常駐性能・走行・画面の改善

- 利用者: 作業中にCPUとAIの使用率を素早く確かめ、ペットを選びたいMac利用者。
- 受け入れ条件: 概要から使用率・停止を確認でき、設定へ1操作で移れる。使用率と残量を混同しない。
- 戦略: 視線を奪わず、必要なときだけ詳細を見せる。
- 要件: CPU/AI、キャラ、連携、自作画像、数値表示、保存・復帰を維持。
- 構造: 概要・設定を分け、連携とテスト操作は設定内に置く。
- 骨格: 見出し、主要数値、使用枠カード、補助情報の順。幅360ptのネイティブポップオーバー。
- 表層: macOS標準色・文字、余白と揃った数値。走行は接地と振り戻しを分け、周期の速度を連続にする。
- 性能: 活動中の絵と合成画像だけを上限付きで再利用。停止時はタイマーを止める。
- 参考: Mobbin、Refero、RunCat公式。考え方を参照し、第三者の素材を製品に取り込まない。
- 検証: 既存テスト、周期の連続性、キャッシュ更新、実操作・撮影、合成データ計測、5分の常駐観察。
- 反映: 機密・個人資料・生成画像を除いてコミット、push、Draft PRを作成する（本人依頼）。
- 改善ループ: 最大3周、同一失敗2周で残件を報告。体験とUIは実挙動で自己点検する。
