# Rust移行・常駐負荷改善

- 目的: 状態・モーション・AIログ解析・CPU/通信量計算をRustへ移し、描画ごとの文字処理とメインスレッドのI/Oを減らす。
- UX: キャラ、CPU/AI残量、停止、数値表示、設定・連携の操作と保存形式を維持。AppKit/SwiftUIがOS表示と設定を担当。
- 対象外: 新機能、実データ/設定ホームのコピー、Git操作、公開、インストール。
- 範囲: Rust/C ABI/Swift接続層、更新スケジュール、ビルド、テスト、関連文書。
- 成功: 既存テスト、ABI・モーション比較、画像確認、合成データによる同条件の性能計測。
- 検証: cargo test/clippy/fmt、Swift Release、既存テスト、画像・ベンチマーク、可能な実操作。未検証は明示。
- 反映: 既存の未コミット内容を退避・ハッシュ記録してから、履歴から回収した変更を元プロジェクトへ反映。
- 改善: 最大3周。同一失敗2周は原因と残件を報告。
