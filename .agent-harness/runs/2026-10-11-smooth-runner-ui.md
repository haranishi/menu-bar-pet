# 走行・UI・常駐性能の追加検証（2026-10-11）

毎フレームの画像生成とステータス項目の幅計算を減らした。走行は接地と振り戻しを分け、足と上下動の速度を周期の継ぎ目まで連続にした。画面は概要・設定に分け、使用率と残量を区別する。

## 設計と確認した参考

[契約](../contracts/smooth-runner-ui.md)でユーザーストーリーとUX5階層を実装前に整理した。これにより、概要の大きな数値、使用枠の2列表示、設定内の連携・動作確認、固定560ptの高さを選んだ。

保存された参考から[Mobbin](https://mobbin.com/)のFitness・Linear画面を目視し、主要数値と補助情報の階層、用途ごとの領域分けを参照した。走行は[RunCat公式デモ](https://kyome.io/runcat/index.html?lang=en)の連続コマを確認。第三者の画像・コードは製品へ取り込んでいない。

## 機械検証と実機操作

- Swift 74/74、Rust 9/9、描画8/8、Domain 5群を通過。
- cargo clippy（警告をエラー扱い）、fmt、release build、アプリ署名の検証を通過。
- 足の接地・回復と上下動の位置・速度の連続性を検証。
- 外観・状態・自作画像・数値変更によるキャッシュの更新と、96/120枚の上限を検証。
- 全キャラ・状態の連続コマとライト/ダークの数値画像を目視。通常2行の文字余白は上6px・下4px。
- AXで開閉、CPU/AI、キャラ、数値、停止・再開、開き直し後の設定維持を確認。
- Spaceキーで停止・再開、画像選択のキャンセル後に操作へ戻れることを確認。
- 操作後は設定データと実行中モデルを元の状態へ戻す。

## 常駐と合成データの性能

ハムスター・AI使用率モード、最大30fps、画面を閉じた状態を、レイヤー更新の導入前後で各300秒観察した。10秒ごとに対象プロセスのpsを30回取得。元のRust移行前アプリとの比較ではない。

| 指標 | 幅計算を毎回行う版 | レイヤー更新版 |
|---|---:|---:|
| CPU中央値 | 22.35% | 1.65% |
| 30秒以降のRSS | 105.2〜107.3MiB | 117.5〜118.7MiB |

CPUは約93%低下した。メモリは増えており、削減を達成したとは判断しない。画像とCGImageの保持によるCPU・メモリの交換条件がある。5分間の上限付きキャッシュは安定していたが、長期のバッテリー消費・メモリ推移は未評価。[数値](2026-10-11-live-soak.json)

反復する12ポーズを2000回処理する合成データ計測では、3回の中央値が210.71ms→7.70ms（約96%短縮）。キャッシュを再利用できる条件の結果で、全処理・全キャラの改善率ではない。[条件と全試行](2026-10-11-frame-cache-benchmark.json)

## ハーネスの改善経過

1. 走行・キャッシュ・概要/設定を実装。機械検証を通過し、実機で配置を確認。
2. 使用枠を遅延グリッドへ変更したところ、実機でレイアウト更新が繰り返され応答しなくなった。プロセスのsampleで特定。
3. 通常の横並びへ変更して復帰。常駐計測からステータス画像の毎回の幅計算も見つけ、レイヤー更新で減らした。主要操作と各5分の計測を実施。

画面の対象はmacOSの360×560pt固定ポップオーバー。Webの画面幅は対象外。以下は独立評価ではなく、実画面・実操作に基づく自己点検。

| UI項目 | 点 | 証拠 |
|---|---:|---|
| 3秒理解 | 2 | 概要に指標・大きな使用率・残量 |
| 視覚階層 | 2 | 見出し、使用枠、リセット時刻を区別 |
| 配色 | 1 | 標準色と警告の文言。実機はダーク、グラファイト |
| 余白・整列 | 2 | 概要/設定を撮影し、2列と数値を確認 |
| 文字 | 2 | 主な数値38pt、本文13pt、時刻11pt |
| 対象幅 | 2 | 360ptで横はみ出しなし、縦はスクロール |
| 導線 | 2 | 指標と停止は概要、詳細は設定から操作 |
| 一貫性 | 2 | 両画面のカード・見出し・フッターを確認 |
| アクセシビリティ | 1 | Space・AX名称・状態・無効化を確認。VoiceOver未試験 |
| 体感速度 | 2 | 操作と各5分の計測、閉じた画面の処理停止 |

UI自己点検18/20。体験は主要タスク・反応・復帰・保存を実操作で確認。異常な入力は自作画像・連携の既存テストで確認したが、すべてのエラー表示は実機で網羅していない。
