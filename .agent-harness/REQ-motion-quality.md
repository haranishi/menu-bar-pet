# REQ: メニューバーペットの動きを「走っている」ように見せる

対象リポ: menu-bar-pet （Swift 6 / SwiftPM / macOS 14+ / AppKit）
起票: 2026-08-25 ／ 目的: 「動きが滑らかでない」を構造から解消する

## 0. 背景（コードを読んでも分からないこと）

本アプリの中心仮説は「好きな画像1枚がMacの状態に反応して**生きて見える**」こと。
現状は仮説の検証以前に、動きが「浮遊するアイコン」に見えており、ユーザーテスト
（写真5人・自作イラスト5人）に出しても仮説の可否を判定できない。よって
機能追加ではなく**モーション品質だけ**を対象にする。

## 2. 設計判断（変更不可・理由込み）

**方式転換：CALayer の外形アニメーション → タイマー駆動の毎フレーム再描画。**
1枚絵を剛体で動かす限り走行には見えない。潰し・伸ばし・傾き・影・接地を位相に
同期させるには毎フレーム描き直すしかない。`PetRenderer` は既に `phase` を
受け取る設計なので、配線し直す。CALayer 版は破棄する。

- **描画レート**: 既定12fps。`onFire`/`sweating` は15fps、`resting` は8fps。
  `Timer` + tolerance で足りる。`CVDisplayLink` は過剰なので使わない。
- **位相は連続変数**: `phase = (phase + dt / cycleDuration).truncatingRemainder(1)`。
  **状態が変わっても位相をリセットしない**（D5）。
- **cycleDuration は CPU の連続関数**（D6）。5段階の離散値をやめる。
  平滑化済み CPU 0→100% に対し単調減少（例 1.4s → 0.30s）。
- **影は本体と分離して描く**（D3）。本体が上がったら影は小さく薄く。
- **走りサイクルは非対称**（D4）: 上昇は ease-out、下降は ease-in。sin をやめる。
- **回転軸はペットの足元**（D7）。`PetRenderer` 内で原点を足元に取る。
- **Retina を明示**（D8）: `NSBitmapImageRep` を 2x で確保して描き、`NSImage` に
  addRepresentation する。`isTemplate = false` は維持（カラー表示のため）。
- **振幅を知覚可能まで上げる**（D2）: resting 0.5 → normal 1.5 → running 2.5 →
  sweating 3.0 → onFire 3.5 pt を目安。**キャンバス外へはみ出さないこと**。
- **Reduce Motion と一時停止ではタイマーを止める**（省電力・アクセシビリティ）。

## 6. UX5階層を通して出た追加仕様（戦略層から導出・5件）

**戦略層**: 目的は情報伝達ではなく**生命感**。10人テストで「翌日も起動したいか」を
判定するのが唯一のゴール。CPU値を正確に伝えることではない。

**要件層**: 見るのは**周辺視野**（視界の隅）。周辺視野は動きに敏感で形と色に鈍い。
一方で「気づく」と「気が散る」は紙一重。

**構造層**: 影・本体・オーバーレイの3レイヤーを独立に動かす。
**骨格層**: 22pt の高さに、影・本体・バウンス幅を収める。
**表層**: メニューバーは明背景と暗背景の両方がある。

### 追加仕様

- **S1（戦略層→D6）**: 速度は連続化するが**両端をクリップする**。CPU 0% でも
  完全停止させず、ごく小さな呼吸（周期 ~2.2s）を残す。止まると「死んで」見え、
  仮説検証にならない。CPU 100% 側も速すぎると何か分からなくなるので周期 0.30s で下限を打つ。
- **S2（要件層→振幅設計）**: 振幅を**一律に上げない**。`resting` は小さいまま
  （0.5pt前後）、高負荷だけ大きくして**コントラストを付ける**。周辺視野に効くのは
  絶対量ではなく変化量。アイドル時に大きく動くと「邪魔」判定で即アンインストールされる。
- **S3（要件層→オーバーレイ）**: 汗・炎は静止した形ではなく**位相同期で脈動**させる
  （スケール ±15% 程度）。周辺視野は形より動きに反応する。
  ただし**明滅（チカチカ）は禁止**。不透明度は一定に保ち、大きさだけ変える。
- **S4（骨格層→レイアウト再設計・重要）**: 現在ペットは
  `NSRect(x:4, y:3, width:34, height:18)` に aspect fit している。ここにバウンス
  3.5pt を足すと上端が 24.5pt となり 22pt のキャンバスをはみ出す。
  **振幅を下げて回避してはならない（D2 が直らない）。**
  本体の描画高を 15pt 程度へ下げ、影を y=1、本体ベースを y=3、バウンス上限を
  y=6.5 に収める形へ**レイアウトごと再設計する**こと。
- **S5（表層→検証）**: フィルムストリップは明背景・暗背景の2種を必ず出す（§4-B に反映済み）。
