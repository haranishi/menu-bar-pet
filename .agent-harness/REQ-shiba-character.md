# REQ: 柴犬キャラクター（新・既定キャラ）

対象リポ: menu-bar-pet ／ 起票: 2026-08-29
本人決定: 「ハムスターだと分かりにくい」→ 判別力最優先で**柴犬**を新規実装し**既定キャラ**にする。

## 0. 背景（設計判断の理由）

ハムスターが読めない主因は構図（円の中の丸い動物＝輪郭がつぶれる）。柴犬は**回し車なし・canvas 42×22ptを1体に全部使う横向き走り**で作る。判別の決め手は**立ち耳（三角2つ）＋巻き尾（クルン）＋白マズル/胸**のシルエット。ハムスターは選択肢として残す（既定からは外す）。

## 1. キャラ仕様

- `PetCharacter` に `.shibaInu`（displayName「柴犬」）を追加し、**既定値と不正値フォールバックを shibaInu に変更**（保存済みの hamsterWheel 選択は尊重）
- **配色**: 柴の茶（オレンジブラウン）＋白（マズル・胸〜腹・尾先・脚先）＋濃色の鼻・目・輪郭。light/dark の外観連動はハムスターで導入済みの `isDarkAppearance` 方式に追随（輪郭・影・Zマークを出し分け。体色は共通でよい）
- **体格**: 高さ〜19pt級・横長。線はアイコン調に太く（ハムスターr2と同等の太さ基準）

## 2. モーション（Coreに純関数・ShibaMotion等として追加）

| 状態 | 表現 |
|---|---|
| resting | **伏せて寝る**（丸まり・目閉じ・静止Z・呼吸±0.3ptのみ。脚・尾は静止） |
| normal / running | 横向き走行。**4脚を実際に描いて前後ペア逆位相で振る**＋バウンス（既存 `cycleDuration(cpu:)` クロック・位相連続）＋接地で潰れ・滞空で伸び＋速度に応じた前傾 |
| sweating | 走行＋汗滴（頭上右・overlayPulse脈動・本体と重ねない） |
| onFire | 全力疾走＋炎（後方・同上） |

- **バウンスは非対称**（上昇 ease-out・下降 ease-in。sin波にしない）※猫ハーネスで実証済みの知見
- **影は本体と分離**して地面に固定（本体が上がると小さく薄く）。resting では脈動を状態強度で減衰
- fps は既存の「1周期最低12コマ保証・上限30」をそのまま利用
- 巻き尾は走行時にわずかに揺らしてよい（±10%以内・ちらつき禁止）
